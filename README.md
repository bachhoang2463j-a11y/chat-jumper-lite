# 跳转楼层 Chat Jumper Lite

超轻量酒馆助手（TavernHelper）插件：跳转到指定楼层，快速回顾以前的剧情。

## 安装

酒馆助手 → 脚本库 → 全局 → 新建脚本，粘贴 `jump-lite.js` 全文并启用。

## 使用

1. 点击酒馆顶部魔棒（扩展抽屉）里的「跳转楼层」。
2. 输入楼层号（0 ~ 最大楼）→ 目标楼 + 后续 4 楼共 5 楼立即显示，目标楼闪烁高亮并对齐视口顶部。
3. 上下滑动到窗口边缘时自动分帧加载前后各 5 楼（滚轮/触屏，rAF 分帧不卡顿）。
4. 区间模式下再次点击入口 → 确认弹窗：确定 = 恢复完整显示（重载聊天），取消 = 继续跳转。

## 性能设计

- 跳转用「区间重建」（参考 ST-Chat-Jumper）：只渲染 5 楼窗口，无论聊天多长，跳转成本恒定；
  不像原生 `/chat-jump` 会一次性同步渲染中间所有楼层（2000 楼聊天会冻结数秒）。
- 滑动补齐用「rAF 分帧 + 视口补偿」（参考 cocktail）：每帧 3 楼，向上补齐时逐帧补偿
  scrollTop，视口不跳；每批结束 emit `MORE_MESSAGES_LOADED` 兼容其他扫描型插件。
- 跳转/补齐插楼后逐楼补发 `USER/CHARACTER_MESSAGE_RENDERED` 事件（移植自 ST-Chat-Jumper）：
  `addOneMessage` 不走酒馆正常渲染管线，渲染类扩展（酒馆助手 JS-Slash-Runner）靠这些事件
  挂载楼层内组件 iframe；补发事件可让代码块组件在跳转和滑动补齐后正常渲染，不残留裸代码块。
- 补齐触发以滚轮/触屏意图为主、scroll 位置兜底：代码块被渲染成 iframe 后，悬停其上的
  滚轮/触屏事件不冒泡出 iframe，但浏览器滚动链仍会滚动聊天容器并派发 scroll 事件，
  按“滚动方向 + 贴边位置”兜底触发，避免区间末尾是代码块组件楼时向下滑动冻结。
- 恢复用 `reloadCurrentChat`，交还酒馆原生截断渲染。

## 调参

脚本顶部常量：`WINDOW_SIZE`（初始窗口楼数，默认 5）、`BATCH_SIZE`（滑动每批楼数，默认 5）、
`EDGE_THRESHOLD`（贴边触发距离，默认 300px）。

## 测试
